# Practice

The app now includes a simple local practice timer with start, pause, reset, and 5, 10, and 20 minute presets. The timer is intentionally quiet: it does not track history, send analytics, or require an account.

Future candidates include tempo ladders, gap click, random silence, and optional local-only practice history.

V1 should not add advanced analytics. Any tracking must remain optional, local-first, and secondary to the click.
