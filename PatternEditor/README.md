# Pattern Editor

SwiftUI pattern work has started with dedicated Play, Edit, Patterns, and Setlist tabs. The Patterns tab supports saved pattern switching, duplication, and protected deletion. The Edit tab supports BPM editing, tap tempo, name editing, meter switching, subdivision switching, and beat accent cycling.

Remaining V1 editor work should keep this simple: restore/default reset actions, explicit custom grouping, and deeper per-beat sound editing without introducing a full sequencer too early.
